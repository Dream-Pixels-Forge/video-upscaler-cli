video-upscaler-cli

High-precision video upscaling CLI and Python library using FFmpeg filter pipelines. Transform video from 360p to 8K with denoise, lanczos scale, unsharp sharpen, and deband.

Installation

Install from PyPI and verify the CLI is available.

pip install video-upscaler-cli
video-upscale --help

Architecture

Four-stage pipeline: probe → calculate → filter → encode.

1

Probe

Extracts metadata via ffprobe: resolution, codec, pixel format, duration, FPS, audio codec, aspect ratio, color space. Validates file existence and video stream presence.

2

Calculate

Resolution calculator determines target dimensions from preset, fit strategy (fit/pad/crop), scale factor, or custom width/height. Enforces even-integer constraints for chroma subsampling.

3

Filter

Assembles ffmpeg -vf graph: optional denoise (hqdn3d), lanczos scaling with accurate rounding, unsharp edge restoration, optional debanding.

4

Encode

Runs ffmpeg with the filter pipeline, configurable codec (libx264 default), x264 preset/CRF from quality profile, yuv420p pixel format, and audio stream copy.

Python API

Programmatic access for AI agents and scripts.

from video_upscaler import Upscaler, UpscaleConfig, Preset, FitStrategy, QualityProfile, DenoiseLevel

config = UpscaleConfig(
    preset=Preset.RES_4K,
    fit=FitStrategy.FIT,
    quality=QualityProfile.HIGH,
    denoise=DenoiseLevel.GENTLE,
    sharpen=True,
    deband=False,
)

upscaler = Upscaler(config)
result = upscaler.upscale("input.mp4", "output_4k.mp4")

print(result.output_path)   # Path to output file
print(result.resolution)    # (width, height) tuple
print(result.duration)      # Duration in seconds

AI Agent Guide

Works with Claude, Codex, Pi, Opencode, Kimi, and other AI coding agents.

Claude / Claude Code

Use the Python API via direct import or subprocess for batch upscale jobs.

from video_upscaler import Upscaler, UpscaleConfig, Preset

Codex

Call the video-upscale CLI from generated scripts.

video-upscale input.mp4 -p 4k --quality high

Pi / Opencode

Returns structured UpscaleResult with output_path, resolution, duration.

result = upscaler.upscale(input, output)

Kimi / Other

All types are standard library dataclasses and enums.
