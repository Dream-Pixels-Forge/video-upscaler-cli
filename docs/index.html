Architecture

The system follows a four-stage pipeline: Probe → Calculate → Filter → Encode.

1
Probe — Extracts media metadata via ffprobe: resolution, codec, pixel format, duration, FPS, audio codec, aspect ratio, color space. Validates file existence and video stream presence.
2
Calculate — Resolution calculator determines target dimensions from preset (720p, 1080p, 2K, 4K, 8K + DCI), fit strategy (fit/pad/crop), scale factor, or custom width/height. Enforces even-integer constraints for chroma subsampling and validates minimum 360p input.
3
Filter — Assembles ffmpeg -vf graph: optional denoise (hqdn3d), lanczos scaling with accurate rounding and full chroma handling, unsharp edge restoration, optional debanding. Parameterized by quality profile and denoise level.
4
Encode — Runs ffmpeg with the filter pipeline, configurable codec (libx264 default), x264 preset/CRF from quality profile, pixel format yuv420p, and audio stream copy. Progress reported by parsing ffmpeg stderr timecodes.

Python API

from video_upscaler import Upscaler, UpscaleConfig, Preset, FitStrategy, QualityProfile, DenoiseLevel

config = UpscaleConfig(
    preset=Preset.RES_4K,
    fit=FitStrategy.FIT,
    quality=QualityProfile.HIGH,
    denoise=DenoiseLevel.GENTLE,
    sharpen=True,
    deband=False,
)

upscaler = Upscaler(config)
result = upscaler.upscale("input.mp4", "output_4k.mp4")

print(result.output_path)   # Path to output file
print(result.resolution)    # (width, height) tuple
print(result.duration)      # Duration in seconds

AI Agent Guide

This package works with Claude, Codex, Pi, Opencode, Kimi, and other AI coding agents. The video_upscaler Python package exposes a clean, typed API that agents can call directly.

Claude / Claude Code

Use the Python API via subprocess or direct import. Ideal for scripting batch upscale jobs in agent workflows.

from video_upscaler import Upscaler, UpscaleConfig, Preset

Codex

Call the video-upscale CLI from generated scripts. Parse stdout for resolution and duration results.

video-upscale input.mp4 -p 4k --quality high

Pi / Opencode

Integrate into agentic pipelines. The Upscaler returns structured UpscaleResult with output_path, resolution, and duration.

result = upscaler.upscale(input, output)

Kimi / Other

Use any LLM to generate Python or shell code that invokes the package. All types are standard library dataclasses and enums.

pip install video-upscaler-cli

Install the package

Install video-upscaler-cli from PyPI. Verify the installation by running `video-upscale --help` and confirm the CLI is available.

Upscale a video to 4K

Use video-upscaler-cli to upscale "input.mp4" to 4K resolution with high quality and gentle denoising. Save the output as "output_4k.mp4". Report the output resolution and duration.

Batch upscale multiple videos

Write a Python script using video_upscaler.Upscaler to batch upscale all MP4 files in a directory to 1080p with medium quality. Use FitStrategy.FIT and DenoiseLevel.GENTLE. Print each result's output_path, resolution, and duration.

Upscale to 8K with memory constraints

Upscale "input.mp4" to 8K using video-upscaler-cli with --quality fast to fit within limited memory. Preserve the audio stream. Confirm the output resolution is 7680×4320.

Check video info before upscaling

Use the video_upscaler.VideoProbe to probe "input.mp4" and report the width, height, codec, FPS, duration, and audio codec. Then recommend the best preset for upscaling.

Custom 2x scale with padding

Use video-upscaler-cli to scale "input.mp4" by 2x with pad fit strategy. Output to "output_2x_padded.mp4". Enable debanding for smooth gradients.
